# Claude Code on Windows — 30-Minute Mentorship Playbook

**👉 Read the full playbook here: https://jomojo0202.github.io/claude-code-setup/**

A complete kit for teaching non-developers how to install and start using Claude Code on Windows in 30 minutes.

## What's in this repo

- [`index.md`](./index.md) — site homepage (overview, audience, what gets installed)
- [`01-walkthrough.md`](./01-walkthrough.md) — minute-by-minute live demo script for the instructor
- [`02-outline.md`](./02-outline.md) — 8-slide structure with talking points
- [`03-handout.md`](./03-handout.md) — clean cheatsheet for attendees to keep
- [`pdfs/`](./pdfs) — PDF versions of all three docs, ready to print or share

## Run the session

1. Open [the website](https://jomojo0202.github.io/claude-code-setup/) — that's the polished version.
2. Skim the walkthrough the day before.
3. Hand out the PDF (or the handout page link) to attendees.
